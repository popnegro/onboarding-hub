⚡ QUICK START EN 15 MINUTOS
════════════════════════════

# 1. Descomprimir
tar -xzf onboarding-hub.tar.gz
cd onboarding-hub

# 2. Push a GitHub
git init
git add .
git commit -m "Initial: Onboarding Hub"
git remote add origin https://github.com/TU_USUARIO/onboarding-hub.git
git push -u origin main

# 3. En vercel.com:
   - Importar repo desde GitHub
   - Agregar 3 env vars (del Supabase):
     * NEXT_PUBLIC_SUPABASE_URL
     * NEXT_PUBLIC_SUPABASE_ANON_KEY
     * SUPABASE_SERVICE_ROLE_KEY
   - Deploy

# 4. ✅ Listo!
   - URL en producción en 5 minutos
   - 4 clientes visibles
   - Checklist funcionando
